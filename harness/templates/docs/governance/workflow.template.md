# Workflow

## Task states

`proposed -> approved -> in_progress -> completed`

Exceptional terminal states are `blocked` and `rejected`.

## Rules

1. Define one task with acceptance criteria.
2. Obtain explicit human approval.
3. Implement the smallest coherent increment.
4. Run deterministic checks and record concise evidence.
5. Obtain human closure approval before the final commit.

AI output cannot approve work or certify its own result. Evidence must identify the command or observation that supports the conclusion.
