# ADR-0001: Adopt Strict Luminous Architecture

- Status: Proposed
- Date: 2026-09-02

## Context

The MVP needs a small structure that remains understandable to humans and AI agents.

## Decision

Use the strict dependency direction from `haiaty/luminous_architecture`. Keep Fastify outside `src/`, expose services only, and create feature, operation, and job implementations only when their semantics are needed.

## Consequences

- Architecture boundaries are simple and machine-checked.
- `process.cwd()` imports require commands to start from the repository root.
- Driver-to-driver composition and same-layer calls are forbidden.
